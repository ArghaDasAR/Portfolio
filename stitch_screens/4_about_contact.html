Argha Das India

I began in the low-level margins—disassembling C kernel drivers and untangling memory layouts on cold CRT terminals. That tactile obsession with machine semantics evolved into building resilient distributed systems and hyper-refined design interfaces.

Over the past decade, I have led core engineering teams at scale, architected zero-downtime platforms handling billions of transactions, and authored component libraries where every token, stroke, and motion curve serves a deliberate human intent.

I operate at the intersection of high-rigor runtime correctness and nuanced typographic poise. Good code should read like literature; user interfaces should feel calm, inevitable, and unhurried.
